ABSTRACT

In today's digital knowledge economy, computer professionals, students, and corporate personnel routinely spend upwards of 8 to 12 hours seated in front of digital visual display terminals. Prolonged static sedentary posture has been epidemiologically linked to widespread musculoskeletal disorders (MSDs), including forward head syndrome ("tech neck"), lumbar spinal compression, thoracic kyphosis, repetitive strain injuries (RSI), and cardiovascular fatigue. While conventional wellness advice recommends frequent physical movement and ergonomic breaks, knowledge workers consistently fail to comply due to immersion in intensive workflows, forgetfulness, lack of immediate feedback, and the perceived friction of finding suitable office-appropriate stretches.

PostureFit is an interactive, gamified, web-based workplace posture awareness and activity platform engineered to address this critical public health problem. Designed and developed as a responsive single-page web application, PostureFit synergistically unites configurable ergonomic work-interval timers (e.g., 25-minute Pomodoro and 50-minute sustained work cycles), persistent desktop audio-visual rest-break notifications, an extensive catalog of 5-minute desk-friendly corrective activities, and interactive Three.js 3D biomechanical skeletal animations that clearly illustrate proper stretching biomechanics in virtual 3D space.

To transform sporadic movement into permanent behavioral habits, the system incorporates a behavioral economics gamification engine featuring real-time experience points (XP), cumulative activity streaks, dynamic leveling algorithms, and commemorative milestone achievement badges. The platform is architected upon a high-performance modern web stack utilizing React 18 with Tailwind CSS on the frontend, an asynchronous Node.js and Express.js RESTful application layer, and a cloud-hosted Supabase PostgreSQL relational database equipped with Row-Level Security (RLS) policies.

Rigorous unit, integration, and user-acceptance test evaluations confirm that PostureFit significantly enhances break adherence, fosters postural ergonomic mindfulness, and delivers a frictionless, zero-install workplace wellness solution accessible from any standard web browser.

1.1. INTRODUCTION

In contemporary workplaces and modern academic environments, digital display terminals, laptops, and desktop computers are indispensable tools for daily productivity. However, this profound technological shift has precipitated a pervasive public health crisis: protracted, unbroken sedentary sitting. Knowledge workers, software developers, researchers, students, and administrative personnel routinely sit for continuous blocks of 4 to 8 hours without interspersing regular physical movement or postural resets.

Biomechanical and occupational ergonomics literature establishes that prolonged static seating exerts intense hydrostatic pressure on the lumbar intervertebral discs, causes chronic shortening of hip flexors, produces cervical spine hyperextension ("forward head syndrome" or "tech neck"), and significantly degrades blood circulation. Over time, these conditions manifest as debilitating Musculoskeletal Disorders (MSDs), repetitive strain injuries (RSI), chronic tension headaches, and diminished workplace cognitive focus.

The PostureFit platform is engineered as an interactive, gamified, web-based workplace posture awareness and activity intervention system. Developed using modern web engineering principles, PostureFit aims to bridge the gap between ergonomic theory and actual human habit formation by combining unobtrusive work timers, desktop rest-break alerts, an extensive catalog of 5-minute desk exercises, interactive 3D skeletal posture guidance, and gamified reward feedback.

Scope of the Project

The functional scope of PostureFit encompasses the complete end-to-end design, implementation, and deployment of a responsive, cloud-connected single-page web application. The platform provides:

  • Ergonomic Sitting & Break Timer: Configurable focus intervals (e.g. 25-min Pomodoro or 50-min deep work) with non-intrusive audio-visual break prompts.
  • Interactive 3D Biomechanical Exercise Visualizer: Real-time rendered 3D anatomical skeletal animations illustrating exact joint alignments and stretch dynamics in the browser.
  • Curated 5-Minute Desk Exercise Catalog: Targeted movement routines organized across Neck, Shoulders, Upper Back, Lower Back, Wrists/Hands, and Core areas.
  • Behavioral Gamification Engine: Transparent reward logic featuring experience points (XP), consecutive daily streaks, dynamic leveling, and achievement badges.
  • Multi-Dimensional Analytics Dashboard: Historical telemetry and Chart.js visualizations tracking daily focus time, completed breaks, and weekly ergonomic adherence.
  • Administrative Content Management: Secure back-office portal allowing administrators to author, update, and manage exercises and multi-step wellness challenges.

Significance of the Project

The significance of PostureFit lies in its low-friction accessibility, preventive health benefits, and innovative synthesis of 3D computer graphics with behavioral psychology. Unlike costly proprietary enterprise solutions or invasive camera-based trackers that raise severe employee privacy concerns, PostureFit operates entirely inside standard modern web browsers with zero installation requirements, zero biometric surveillance, and minimal computational overhead.

The conceptualization and development of PostureFit: A Gamified Web-Based Workplace Posture Awareness and Activity Platform were motivated by several compelling real-world catalysts across occupational health, behavioral psychology, and software engineering:

With millions of professionals and students working remotely or in cubicle desk settings, there is an urgent need for preventive digital health tools that actively encourage routine movement breaks.

2. Ineffectiveness of Passive Ergonomic Advice

Most workplace wellness programs rely on passive measures such as static posters, PDF booklets, or one-time ergonomic seminars. Research demonstrates that passive knowledge fails to generate consistent behavioral compliance; when individuals enter high-stress "flow states" or tight deadlines, ergonomic mindfulness is immediately forgotten. A software intervention must provide active, contextual, timed nudges to successfully disrupt static postures.

Behavioral psychology shows that sustainable habit formation requires three interconnected elements: an unambiguous trigger, an effortless routine, and an immediate gratifying reward. By introducing experience points (XP), cumulative daily streaks, level progression milestones, and unlockable achievement badges, PostureFit transforms the tedious obligation of stretching into an engaging, intrinsically rewarding micro-challenge.

Conventional fitness apps present stretching exercises through static 2D stick drawings or generic text descriptions, which often fail to convey critical nuance regarding spine alignment, chin tuck angles, or shoulder retraction. 1.3. FACT-FINDING Q&A (PART 1)

To establish solid empirical and operational requirements for PostureFit, extensive fact-finding interviews, workplace ergonomic surveys, and technical literature analyses were conducted with university students, IT professionals, and ergonomics research papers.

Q1: What are the primary health hazards experienced by desk workers during prolonged sitting?

A1: Desk workers face significant ergonomic strain, predominantly in the cervical, thoracic, and lumbar spine regions. Key manifestations include chronic muscular knots in the trapezius, forward head displacement ("tech neck") placing up to 27 kg of effective strain on cervical vertebrae, lumbar lordosis flattening leading to disc herniation, carpal tunnel inflammation in the wrists, reduced circulatory venous return, and eye fatigue associated with computer vision syndrome.

Q2: Why do computer users consistently forget or ignore taking regular posture breaks?

A2: Knowledge workers enter deep psychological cognitive absorption ("hyperfocus" or "flow state") during intensive coding, writing, or analysis tasks. Without an automated, multisensory external cue, human time perception compresses, causing workers to remain stationary for 3 to 4 hours uninterrupted. Furthermore, users report that when they do remember, they lack immediate knowledge of quick, non-disruptive exercises suitable for an office environment.

Q3: What specific capabilities do users expect from an effective workplace posture application?

A3: Stakeholders demand: (1) an unobtrusive, configurable sitting/work timer; (2) polite audio and visual desktop reminders that do not violently disrupt critical workflows; (3) ultra-short, desk-friendly activities that require less than 5 minutes and no special clothing or gym gear; (4) visually intuitive exercise instructions that guarantee safe form; and (5) automated progress logging that validates daily wellness habits.

Q4: How does gamification influence long-term adherence to ergonomic exercises?

A4: Gamification leverages established behavioral feedback loops (dopamine release and loss aversion). Rewarding completed activities with instant Experience Points (XP) delivers positive reinforcement. Daily streak counters exploit habit momentum, encouraging users to maintain consecutive days of posture mindfulness. Milestone badges provide tangible markers of long-term mastery, turning health compliance into a personal game.

Q5: Why is interactive 3D skeletal visualization superior to static text or 2D diagrams?

A5: Biomechanical stretches depend heavily on subtle 3D rotational mechanics—such as thoracic spine extension, scapular retraction, and pelvic neutral alignment—which cannot be adequately represented by flat 2D illustrations. A 3D skeletal rig rendered in the browser allows dynamic multi-angle inspection, smooth continuous cycle animation, and clear visualization of target joints, preventing injury from improper form.

1.3. FACT-FINDING Q&A (PART 2)

Q6: What are the key technical challenges in implementing reliable background timers in web browsers?

A6: Modern web browsers enforce aggressive power-saving CPU throttling on background and inactive browser tabs, causing traditional JavaScript setInterval() timers to drift significantly or pause entirely. PostureFit resolves this by computing elapsed time against real-world epoch timestamps (Date.now()) on every tick and synchronizing state transitions with local storage and Web Audio API contexts.

Q7: Why was a web-based architecture selected instead of a native desktop application?

A7: A web-based Single Page Application (SPA) eliminates OS-specific compilation barriers, enables instant zero-install access across Windows, macOS, and Linux operating systems, ensures automatic zero-maintenance software updates, and operates safely inside corporate environments where strict IT policies prohibit installing third-party native executables (.exe or .pkg).

Q8: How does PostureFit protect user privacy and sensitive corporate workplace data?

A8: Unlike invasive webcam-based posture solutions that process live video feeds, PostureFit collects zero biometric or camera imagery. All stored telemetry is strictly restricted to anonymous work session durations, completed exercise IDs, and earned gamification points. Furthermore, all data in Supabase PostgreSQL is protected through Row-Level Security (RLS) policies and bcrypt password hashing.

Q9: What makes a desk exercise truly "office-appropriate"?

A9: Office-appropriate exercises must satisfy five rigorous criteria: (1) feasibility while seated or standing immediately beside a desk; (2) zero requirement for floor contact or athletic attire; (3) low physical exertion that does not induce perspiration; (4) completion duration under 5 minutes; and (5) targeted decompression of muscle groups specifically stressed by sitting (cervical spine, pectorals, wrists, and hip flexors).

Q10: What is the primary operational benefit and expected outcome of the PostureFit platform?

A10: PostureFit successfully establishes an automated, supportive habit architecture that reduces workplace physical fatigue, improves spine alignment awareness, increases blood circulation, and enhances overall focus and productivity without requiring corporate fitness investments or burdensome lifestyle overhauls.

1.5. DISADVANTAGES & SYSTEM LIMITATIONS

In adhering to academic objectivity and rigorous engineering standards, several inherent limitations and operational constraints of the current system are acknowledged:

  1. Dependence on User Voluntary Compliance: As an awareness platform rather than an invasive surveillance tool, PostureFit relies on the user's voluntary willingness to initiate exercises and heed break prompts.

  4. Absence of Automated Posture Detection: The initial system does not employ computer-vision posture classification via webcam; physical exercise completion is self-reported by the user.
  5. Non-Diagnostic Medical Scope: The platform is strictly an ergonomic wellness and habit intervention tool; it does not diagnose clinical spinal pathologies or provide licensed medical rehabilitation therapy.
  6. Hardware Acceleration Dependency for 3D: On extremely antiquated computer hardware lacking WebGL GPU acceleration, rendering complex 3D skeletal animations may exhibit lower framerates.
  7. Audio Permission Restrictions: Strict modern browser autoplay policies require at least one user click gesture before synthetic Web Audio chime frequencies can be sounded.
  8. Display Size Ergonomics: While responsive, the 3D exercise animation player is optimal on desktop/laptop displays where the user can comfortably view stretches from their seated position.

1.6. OVERCOMING FROM CHALLENGES

During the architectural design and full-stack development of PostureFit, several complex technical challenges arose. These were systematically resolved through rigorous software engineering methodologies:

Technical Challenge Engineering Solution Implemented in PostureFit
1. Browser Background Timer Throttling & Drift Modern browsers throttle setInterval() when tabs lose focus. To prevent timer inaccuracy, PostureFit computes elapsed time against absolute epoch timestamps (Date.now()) on every tick, and mirrors active timer timestamps into localStorage, guaranteeing second-accurate countdown precision regardless of tab state.
2. 3D WebGL Rendering Performance Overhead Rendering complex 3D meshes can cause memory leaks and high CPU usage on low-spec laptops. PostureFit designed lightweight procedural skeletal joint primitives in Three.js, utilized efficient quaternion rotations, and implemented automatic WebGL context disposal on modal unmount.

A unified data store mapping layer (server/src/db/store.ts) was established with optional schema fallbacks to guarantee 100% data persistence integrity.
5. Habit Fatigue & User Gamification Engagement Users often abandon repetitive timers after several days. PostureFit engineered an exponential leveling algorithm with dynamic badge unlocking, diverse exercise variety across 5 anatomical categories, and consecutive streak multipliers to maintain long-term habit momentum.
6. Zero-Friction Enterprise Deployment Corporate environments forbid installing external .exe binaries. PostureFit packaged the entire platform as a standard responsive web application hosted on Vite and Node.js, accessible immediately via URL without administrative desktop privileges.

Core System Philosophy

The fundamental design philosophy of PostureFit centers on three core architectural imperatives:

  1. Frictionless Workplace Integration: The application must operate unobtrusively alongside professional software development tools, document editors, and communication applications, consuming minimal CPU and battery resources while providing timely posture interventions.
  2. Empirical Biomechanical Accuracy: All posture guidelines, corrective exercises, and 3D joint movements must reflect established physical therapy and occupational ergonomics guidelines, ensuring that users decompress targeted muscle groups without injury.
  3. Positive Habit Reinforcement: Rather than utilizing punitive or stressful warnings, the platform leverages positive psychology and transparent gamification mechanics (XP, streaks, and commemorative badges) to instill lifelong posture mindfulness.

Scope of Requirements Gathering

The requirements detailed herein were collected through systematic domain research encompassing:

  • Workplace ergonomic field studies analyzing sedentary desk posture risks and intervertebral disc pressure curves.
  • Direct interviews with software developers, data analysts, and university students evaluating digital eye strain and typing fatigue.
  • Technical benchmarking of web browser background throttling, WebGL 3D rendering pipeline limits, and Web Audio API constraints.
  • Relational database normalization for high-concurrency activity logging and streak state machines in Supabase PostgreSQL.

2.2. FUNCTIONAL REQUIREMENTS (PART 1)

Functional requirements specify the concrete algorithmic operations, user interactions, and data transformations executed by PostureFit:

FR-01: User Authentication & Role-Based Authorization

The system shall provide secure user registration and login workflows utilizing email and password credentials. Passwords must be salted and cryptographically hashed using bcrypt. The backend shall verify sessions via signed JSON Web Tokens (JWT) and enforce Role-Based Access Control (RBAC) distinguishing between standard desk workers ('user') and system administrators ('admin').

FR-02: Work Session Sitting & Break Interval Timer

The system shall implement an interactive countdown timer allowing users to configure work sitting intervals (default 25 or 50 minutes) and rest-break durations (default 5 or 10 minutes). The timer must support play, pause, resume, and skip controls, and accurately track time against epoch timestamps to prevent browser tab throttling drift.

FR-03: Multisensory Rest-Break Dispatcher

Upon countdown completion of an active work session, the platform shall immediately dispatch an interactive desktop break modal. It shall concurrently synthesize an ergonomic alert chime via the HTML5 Web Audio API and trigger native OS desktop notifications if permitted by the user.

FR-04: Curated 5-Minute Desk Exercise Catalog

The platform shall present an interactive repository of desk-friendly corrective activities searchable by category (Neck, Shoulders, Upper Back, Lower Back, Wrists, Hips). Each exercise entry must display title, difficulty tier, target muscle group, estimated duration, step-by-step instructions, and expected posture benefits.

FR-05: Real-Time 3D Biomechanical Exercise Visualization

The system shall render an interactive 3D humanoid anatomical skeletal rig using Three.js and HTML5 Canvas. The 3D model shall animate proper stretch biomechanics (e.g. cervical chin tucks, scapular retractions, spinal twists), allowing users to orbit, zoom, and inspect movement form from multiple angles in real time.

2.2. FUNCTIONAL REQUIREMENTS (PART 2)

FR-06: Experience Points (XP) & Dynamic Leveling Engine

The backend gamification service shall automatically calculate and award experience points upon verified event completion (+25 XP for completed work sessions, +50 XP for completed exercises). The service shall dynamically compute user levels using an exponential progression formula (Level = floor(0.1 * sqrt(XP)) + 1) and return updated progress telemetry to the client.

FR-07: Consecutive Daily Streak State Machine

The system shall maintain a consecutive daily activity streak counter for each registered profile. Completing an exercise within the active calendar day shall increment the streak; failure to record activity within 24 hours of the last session shall gracefully reset the streak counter to 1 with motivational recovery messaging.

FR-08: Milestone Achievement Badging System

The platform shall evaluate user qualification against a catalog of milestone achievement badges upon every activity completion. Badges (such as "First Step", "Posture Starter", "Spine Guardian", and "Ergo Champion") shall unlock automatically when specific criteria (XP thresholds, streak counts, or activity volumes) are satisfied, generating celebratory feedback modals.

FR-09: Multi-Dimensional Analytics Dashboard

The application shall provide an executive telemetry dashboard visualizing user historical data through Chart.js charts. Metrics displayed must include total focused sitting hours, weekly completed exercise counts, current vs longest streaks, and categorical exercise distribution.

FR-10: Administrative Content Management Portal

Authorized administrators shall have access to a protected management console enabling full CRUD (Create, Read, Update, Delete) operations over the exercise catalog and guided wellness challenge flows, including publishing status toggles and difficulty calibration.

2.3. NON-FUNCTIONAL REQUIREMENTS (PART 1)

Non-functional requirements define the quality attributes, architectural benchmarks, security parameters, and operational standards of PostureFit:

1. High-Performance & Low Latency

The frontend Single Page Application (SPA) must achieve an initial page load time under 1.8 seconds on standard 4G/broadband connections. Client-side timer state updates and WebGL 3D rendering loops must maintain a stable 60 frames per second (fps) on standard consumer hardware, with client-side API response latencies kept below 250 milliseconds.

2. Architectural Scalability

The application layer must be stateless, delegating persistence to Supabase PostgreSQL to allow seamless horizontal scaling across serverless container instances. The database schema must feature optimized B-tree indexes on foreign keys (user_id, exercise_id, session_id) to support concurrent queries without performance degradation.

3. Usability & Human-Centered Ergonomics

The user interface must be clean, distraction-free, and uncluttered, following modern minimalist design standards. Core actions—such as starting a timer, acknowledging a rest break, or launching a 3D stretch—must be reachable within 2 mouse clicks. Color contrasts must strictly comply with WCAG 2.1 AA accessibility guidelines to prevent eye fatigue.

4. System Reliability & Fault Tolerance

The timer state machine must withstand accidental browser tab closes, page refreshes, and network drops by continuously caching active state in localStorage. The platform must maintain 99.9% uptime, with automated error-handling middleware intercepting and logging database connection exceptions without crashing the server process.

5. Data Security & Privacy Protection

All network communication must be encrypted using HTTPS and TLS 1.3. User passwords must be salted and hashed with bcrypt (cost factor 10). Supabase database tables must be fortified with Row-Level Security (RLS) policies ensuring that users can only read and write their own telemetry records. No webcam or biometric data is ever captured.

Role: Manages ergonomic sitting intervals, epoch drift mitigation, and rest-break triggers. 

import React, { createContext, useContext, useState, useEffect, useRef } from "react";
import { useSound } from "../hooks/useSound";
import { useNotification } from "../hooks/useNotification";

export interface TimerContextType {
  mode: "work" | "break";
  timeRemaining: number;
  isRunning: boolean;
  workIntervalMinutes: number;
  breakDurationMinutes: number;
  startTimer: () => void;
  pauseTimer: () => void;
  resetTimer: () => void;
  skipToBreak: () => void;
  snoozeBreak: (minutes?: number) => void;
}

export const TimerProvider: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  const [mode, setMode] = useState<"work" | "break">("work");
  const [workIntervalMinutes] = useState(25);
  const [breakDurationMinutes] = useState(5);
  const [timeRemaining, setTimeRemaining] = useState(25 * 60);
  const [isRunning, setIsRunning] = useState(false);
  const targetEpochRef = useRef<number | null>(null);

  const { playBreakChime } = useSound();
  const { showDesktopNotification } = useNotification();

  // Epoch-synchronized timer tick prevents browser background throttling drift
  useEffect(() => {
    let intervalId: any = null;
    if (isRunning) {
      if (!targetEpochRef.current) {
        targetEpochRef.current = Date.now() + timeRemaining * 1000;
      }
      intervalId = setInterval(() => {
        const remainingSeconds = Math.max(0, Math.round((targetEpochRef.current! - Date.now()) / 1000));
        setTimeRemaining(remainingSeconds);

        if (remainingSeconds <= 0) {
          clearInterval(intervalId);
          setIsRunning(false);
          targetEpochRef.current = null;
          handleIntervalCompletion();
        }
      }, 1000);
    }
    return () => clearInterval(intervalId);
  }, [isRunning]);

  const handleIntervalCompletion = () => {
    if (mode === "work") {
      playBreakChime();
      showDesktopNotification("Posture Break Required", "Stand up and stretch for 5 minutes!");
      setMode("break");
      setTimeRemaining(breakDurationMinutes * 60);
    } else {
      setMode("work");
      setTimeRemaining(workIntervalMinutes * 60);
    }
  };

  const startTimer = () => setIsRunning(true);
  const pauseTimer = () => { setIsRunning(false); targetEpochRef.current = null; };
  const resetTimer = () => { setIsRunning(false); targetEpochRef.current = null; setTimeRemaining(workIntervalMinutes * 60); };

  return (
    <TimerContext.Provider value={{ mode, timeRemaining, isRunning, workIntervalMinutes, breakDurationMinutes, startTimer, pauseTimer, resetTimer }}>
      {children}
    </TimerContext.Provider>
  );
};

import React, { useEffect, useRef } from "react";
import * as THREE from "three";
import { OrbitControls } from "three/examples/jsm/controls/OrbitControls";

interface ExerciseAnimation3DProps {
  animationType: "neck_retraction" | "shoulder_roll" | "spine_twist" | "wrist_flex";
}

export const ExerciseAnimation3D: React.FC<ExerciseAnimation3DProps> = ({ animationType }) => {
  const mountRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!mountRef.current) return;
    const width = mountRef.current.clientWidth;
    const height = mountRef.current.clientHeight;

    // Three.js Scene, Camera, & WebGL Renderer
    const scene = new THREE.Scene();
    scene.background = new THREE.Color(0xf8fafc);
    const camera = new THREE.PerspectiveCamera(45, width / height, 0.1, 1000);
    camera.position.set(0, 1.4, 3.2);

    const renderer = new THREE.WebGLRenderer({ antialias: true });
    renderer.setSize(width, height);
    renderer.setPixelRatio(window.devicePixelRatio);
    mountRef.current.appendChild(renderer.domElement);

    const controls = new OrbitControls(camera, renderer.domElement);
    controls.enableDamping = true;

    // Biomechanical Joint Hierarchy (Torso, Cervical Neck, Head)
    const boneMaterial = new THREE.MeshStandardMaterial({ color: 0x2563eb, roughness: 0.3 });
    const jointMaterial = new THREE.MeshStandardMaterial({ color: 0x10b981, roughness: 0.2 });

    const torso = new THREE.Mesh(new THREE.CylinderGeometry(0.12, 0.14, 0.6, 16), boneMaterial);
    torso.position.y = 0.9;
    scene.add(torso);

    const neck = new THREE.Group();
    neck.position.y = 0.35;
    torso.add(neck);

    const head = new THREE.Mesh(new THREE.SphereGeometry(0.12, 16, 16), jointMaterial);
    head.position.y = 0.18;
    neck.add(head);

    // Animation Loop
    let clock = new THREE.Clock();
    let frameId: number;
    const animate = () => {
      frameId = requestAnimationFrame(animate);
      const t = clock.getElapsedTime();

      if (animationType === "neck_retraction") {
        neck.position.z = Math.sin(t * 2) * 0.08; // Chin tuck displacement
        neck.rotation.x = Math.sin(t * 2) * 0.15;
      } else if (animationType === "shoulder_roll") {
        torso.rotation.y = Math.sin(t * 1.5) * 0.3;
      }
      controls.update();
      renderer.render(scene, camera);
    };
    animate();

    return () => {
      cancelAnimationFrame(frameId);
      renderer.dispose();
      if (mountRef.current) mountRef.current.innerHTML = "";
    };
  }, [animationType]);

  return <div ref={mountRef} className="w-full h-64 rounded-lg overflow-hidden border shadow-inner" />;
};

import { getSupabaseClient } from "../db/supabase";

export class GamificationService {
  // Exponential leveling formula: Level = floor(0.1 * sqrt(XP)) + 1
  public static calculateLevel(xp: number): number {
    return Math.floor(0.1 * Math.sqrt(xp)) + 1;
  }

  public static async processActivityReward(userId: string, exerciseId: string, durationSeconds: number) {
    const supabase = getSupabaseClient();
    const XP_AWARD = 50;

    // 1. Record completed activity
    await supabase.from("activity_completions").insert({
      user_id: userId,
      exercise_id: exerciseId,
      xp_awarded: XP_AWARD,
      completion_duration_seconds: durationSeconds
    });

    // 2. Fetch active profile
    const { data: profile } = await supabase.from("profiles").select("*").eq("id", userId).single();
    const newXp = (profile.xp || 0) + XP_AWARD;
    const newLevel = this.calculateLevel(newXp);

    // 3. Evaluate Consecutive Daily Streak
    const today = new Date().toISOString().split("T")[0];
    let newStreak = profile.streak_count || 0;
    if (!profile.last_active_date) {
      newStreak = 1;
    } else {
      const lastActive = new Date(profile.last_active_date);
      const diffDays = Math.floor((Date.now() - lastActive.getTime()) / (1000 * 3600 * 24));
      if (diffDays === 1) {
        newStreak += 1; // Consecutive day maintained
      } else if (diffDays > 1) {
        newStreak = 1; // Streak broken, restart
      }
    }

    // 4. Update profile stats
    await supabase.from("profiles").update({
      xp: newXp,
      level: newLevel,
      streak_count: newStreak,
      last_active_date: today
    }).eq("id", userId);

    // 5. Audit Log in reward_events
    await supabase.from("reward_events").insert({
      user_id: userId,
      event_type: "exercise_completion",
      xp_amount: XP_AWARD,
      description: "Completed 5-min ergonomic posture stretch"
    });

    // 6. Evaluate Badge Eligibility
    const unlockedBadges = await this.evaluateBadgeUnlocks(userId, newXp, newStreak);
    return { xpAwarded: XP_AWARD, totalXp: newXp, level: newLevel, streak: newStreak, unlockedBadges };
  }
}
