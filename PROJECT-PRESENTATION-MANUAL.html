🚀 1. How to Run on Any Laptop or from a USB Pen Drive

If you copy this whole project directory to a USB pen drive or another laptop, here is the exact way to run it:

Method A: 1-Click Double Click

Simply double-click the file named START-POSTUREFIT.bat.

It checks for Node.js, installs any missing packages, starts both servers, and opens your browser automatically at http://localhost:5173!

Method B: Inside VS Code Terminal

1. Open folder in VS Code (File > Open Folder).

2. Open terminal (Ctrl + ~) and type:

npm run dev

3. Open http://localhost:5173 in Chrome or Edge.

Demo Account Available: On the login screen, click the button "Quick Demo Login" to instantly sign in without filling out forms.

Frontend React 18 + Vite + Tailwind CSS + Three.js The user interface you see in the browser. Handles the 3D anatomical mannequin, countdown timers, voice coach buttons, and responsive pages.

🎓 3. Classroom Viva Presentation & Examiner Q&A

Q1: What is the main problem PostureFit solves?

Answer: Computer desk workers and students stay seated for hours without moving, leading to cervical spine strain ("tech neck"), rounded shoulders, and wrist stiffness. PostureFit solves this through structured micro-breaks, 5-minute guided challenges, and gamified streaks.

Q2: How does the timer handle background tabs or laptop sleep?

Answer: Instead of counting down in memory (which gets paused by the browser), PostureFit stores the target end timestamp: targetEndAt = Date.now() + duration in localStorage. When the user returns or wakes their laptop, the visibilitychange event recalculates remaining time against Date.now(), guaranteeing zero clock drift.

Q3: How do you prevent users from cheating and giving themselves infinite points?

Answer: Zero-trust client architecture. The client never submits points to the server. The client only sends an activity ID with a unique idempotency key. The Express server validates the action, calculates points from centralized rules, and writes to an immutable ledger table.

Q4: Why are there different modes for Students vs Office Workers?

Answer: Students typically study on laptops on low desks or in libraries with backpack tension. Office workers sit in corporate cubicles with continuous mouse/keyboard repetitive strain. PostureFit provides tailored filters for both contexts.

Q5: What external services are used, and can this run offline?

Answer: PostureFit uses Supabase (PostgreSQL + Auth) for cloud persistence, the browser's native Web Speech API for voice coaching, and Three.js (WebGL) for 3D animation. However, it features a dual-mode storage bridge: if no internet or cloud credentials exist, it automatically switches to an in-memory persistent store with preloaded demo data, running 100% offline!

Q6: Why is automated AI webcam posture detection considered future scope?

Answer: Per our approved project synopsis, V1 prioritizes habit formation and workplace usability. Running client-side neural network models continuously consumes significant laptop battery/CPU, creates severe privacy concerns in corporate open offices, and risks inaccurate medical claims. We built the core habit engine first and scheduled MediaPipe computer vision for V2.
